# VetGEME P9 visual-state authoring 2026.07.16.2

Пакет связывает уже утверждённый визуальный набор с состояниями P5/P6/P7. Он не
перерисовывает клинику и не меняет live runtime.

Покрытие:

- 12 помещений, из них 11 имеют подходящий room shell;
- 27 единиц оборудования, 14 имеют прямой или явно обозначенный shared sprite;
- 10 сотрудников;
- 9 зон HUD;
- состояния покупки, доставки, подготовки, обучения, обслуживания, нехватки
  расходников, занятости и готовности;
- все видимые статусы написаны обычным русским языком.

Если отдельного изображения нет, пакет требует честную DOM-подпись и не
разрешает подменять capability случайной картинкой. Центр клиники остаётся
свободным; длинные данные открываются в drawers.

```bash
node scripts/build-p9-package.mjs
node scripts/validate-p9-package.mjs
```

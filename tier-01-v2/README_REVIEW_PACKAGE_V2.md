# VetGEME Tier 01 v2 — редакционно заполненный пакет

В пакете:

- 30 клинических случаев;
- точные жалобы, вопросы и ответы для спокойного, наблюдательного, невнимательного и тревожного владельца;
- отдельная библиотека из 32 домашних действий с готовыми репликами;
- семидневный план с однозначным подсчётом визитов;
- тематические цели каждого дня;
- полноценный сценарий первого обучающего приёма;
- усиленный валидатор, который запрещает заглушки и свободно сгенерированный медицинский текст;
- задание для Codex в `CODEX_TASK_TIER_01_V2.md`.

Статус: тексты редакционно завершены, но всё ещё помечены `pending_medical_review`. Это сознательно: перед production-релизом ветеринар должен утвердить клинические формулировки и допустимые упрощения.

Пакет по умолчанию `not_connected`; его нельзя распаковывать поверх production без ветки, резервного коммита и feature flag.
